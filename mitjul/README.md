# 밑줄

> 적기만 하는 기록 말고, 구조가 붙는 기록

## 노션이 아니라 이것인 이유

노션은 **정리를 이미 결정한 사람**을 위한 그릇입니다. 데이터베이스를 만들고, 속성을 채우고,
뷰를 짜고, 다시 들어가 보는 일이 전부 사용자 몫입니다. 그런데 기록이 묻히는 이유는 그릇이
없어서가 아니라 **정리라는 별도의 일이 영원히 일어나지 않아서**입니다.

밑줄의 전제는 하나입니다. **구조는 기록의 부산물이어야 하고, 정리는 사람이 아니라 앱이
내미는 줄이어야 한다.**

- **한 칸에 적으면 구조가 붙습니다.** 유형을 고르고 항목을 채우는 대신, 쓴 글에서 신호를 읽어
  유형과 항목을 정합니다. 링크 · `p.57` · `시편 23:1` · `#갈피` · `30분` · `14:00` · `- [ ]` ·
  따옴표. 읽어낸 것은 칩으로 보이고, 칩을 누르면 그 신호만 되돌아갑니다.
- **정리는 앱이 셉니다.** 구조가 붙지 않은 기록을 세어 검토 탭으로 내밉니다. 사용자는 갈피를
  붙이거나 '이대로 두기' 중 하나만 고르면 끝납니다.
- **기록은 돌아옵니다.** 하루 동안 얼어 있는 세 장(그날의 기록 · 표시함 · 오래 안 읽음)이
  검토 첫 줄에 놓입니다.

## 기록 유형

순간 · 책(밑줄+메모) · 영상(링크+메모) · 묵상(본문 주소+말씀+묵상) · 식사(사진+실천) ·
운동(분+실천) · 글 · 할 일

## 출처가 붙는 흐름 (책·링크)

하루에 수십, 수백 개의 밑줄을 긋는 사람에게 매번 책 제목·저자·쪽수·태그를 묻는 것은
기록이 아니라 노동입니다. 책과 영상은 **출처**로 한 번만 등록하고, 그 뒤로는 문장만 옮깁니다.

- 캡처 칸은 마지막에 읽던 책이 이미 선택된 채 열립니다. 문장만 적고 저장 — 저장해도 칸은
  닫히지 않고 다음 기록을 이어 받습니다.
- **링크는 출처를 스스로 만듭니다.** 유튜브·비메오 링크를 적으면 썸네일이 뜨고 제목·채널은
  oEmbed로 채워집니다(키 없음, 그 밖의 링크는 og 태그). 썸네일은 한 번 내려받아 카드·상세에
  쓰고, 상세에서 누르면 WebView로 그 자리에서 재생됩니다. 같은 링크를 다시 적으면 새 출처를
  만들지 않고 그 영상에 메모를 이어 남깁니다.
- 영상과 글은 `링크` 한 유형이고, 형식(영상/글)은 출처의 종류가 기억합니다 — 기록 탭에서
  형식으로 걸러 볼 수 있습니다.
- 출처 칩을 길게 누르면 이름을 고치거나 지울 수 있습니다. 고친 제목은 그 출처의 밑줄에도
  반영됩니다. 같은 제목을 다시 등록하면 새로 만들지 않고 있던 출처를 씁니다.
- 출처는 `sources` 테이블에, 각 밑줄은 `entries.source_id`로 매달립니다. 서재·내보내기가
  그대로 동작하도록 제목·저자는 밑줄에도 복사해 둡니다. 출처 없이 남긴 옛 기록은
  마이그레이션이 제목별로 출처를 만들어 이어 줍니다.

## 화면

| 탭 | 역할 |
|----|------|
| 수집함 | 오늘 담은 것 · 할 일 · 검토해야 할 양 한 줄 |
| 기록 | 표. 유형·형식(책/영상/글)·갈피·정렬로 걸러 본다 |
| 적기 | 한 칸 캡처 — 구조는 파서가 붙인다 |
| 검토 | 다시 읽기 3장 · 구조 없는 기록 · 오래 안 읽은 기록 |
| 지표 | 실천 격자 · 주간 운동 · 형식별 분포 |

## 디자인 언어

도구의 얼굴. 감성이 아니라 시스템입니다.

- 글자는 한 벌 — IBM Plex Sans KR. 수치·시각·개수는 IBM Plex Mono로 자릿수를 맞춥니다.
  세리프는 쓰지 않습니다.
- 색은 차가운 무채색 하나뿐(#FFFFFF / #0E1116, 밤은 #0B0D10 / #E8EBF0). 선택은 색조가 아니라
  반전으로, 구획은 헤어라인으로 말합니다.
- 모서리는 세우고(6px), 행 높이는 44px로 고정해 표처럼 읽히게 합니다.
- 목소리: '담아두었어요' 대신 '저장됨'. 위로하지 않고 일어난 일만 적습니다.

## 옵시디언 내보내기

하루 한 문서(`YYYY-MM-DD`), YAML 프런트매터(date/types/tags), 유형별 H2 섹션,
blockquote 인용 관례. 설정에서 이번 주/이번 달/전체를 공유 시트로 내보냅니다.

## 기술

- Expo SDK 54 · TypeScript strict · expo-router · expo-sqlite (오프라인 전용, 서버 없음)
- `PRAGMA user_version` 기반 버전드 마이그레이션, 타입드 리포지토리 레이어
- 캡처 파서·날짜·태그·덱 선정·링크·마크다운 빌더는 순수 함수 (`src/core/`) — `npm test`로 검증
- 마이그레이션은 `node:sqlite` 위에서 실제로 실행해 검증합니다 (표 재구축 포함)
- 하루의 경계는 새벽 4시 (자정 넘어 쓴 일기는 어제의 일기)

```bash
npm install
npm run ios        # 개발 실행
npm run typecheck  # tsc --noEmit
npm test           # 코어 유닛 테스트 (node:test + tsx)
```
