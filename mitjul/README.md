# 밑줄

> 쓰기만 하는 기록 말고, 다시 읽는 기록

책에도, 하루에도, 스쳐 간 순간에도 밑줄을 긋는 개인 기록 앱입니다.
여기 남긴 기록은 사라지지 않고 어느 아침, 당신을 다시 찾아옵니다.

## 무엇이 다른가

기록 앱의 진짜 실패는 보관이 아니라 **다시 읽지 않음**입니다. 밑줄은 모든 구조를
"기록이 돌아오는 길"에 맞춰 설계했습니다.

- **다시 만나는 밑줄** — 오늘 탭 맨 위, 매일 다른 세 장의 과거 기록.
  ① 그날의 기록(n년 전 오늘) ② 아껴둔 밑줄 ③ 오래 잊고 있던 문장.
  같은 날에는 항상 같은 덱(날짜 시드 결정적 난수), 한 번 보여준 기록은 30일간 쉽니다.
- **오래 안 읽은 순** — 서재의 정렬. 책장의 먼지를 보이게 합니다.
  상세를 열 때마다 '다시 읽음'이 기록되어, 실제 읽기를 반영합니다.
- **같은 갈피** — 모든 상세 화면 끝에서 태그가 겹치는 기록으로 이어지는 산책로.
- **보내주기** — 더는 만나고 싶지 않은 기록을 죄책감 없이 순환에서 내보냅니다.

## 기록 유형

순간 · 책(밑줄+메모) · 영상(링크+메모) · 묵상(본문 주소+말씀+묵상) · 식사(사진+실천) ·
운동(분+실천) · 글 · 할 일

## 밑줄 긋기 흐름

하루에 수십, 수백 개의 밑줄을 긋는 사람에게 매번 책 제목·저자·쪽수·태그를 묻는 것은
기록이 아니라 노동입니다. 책과 영상은 **출처**로 한 번만 등록하고, 그 뒤로는 문장만 옮깁니다.

- 캡처 시트는 **마지막에 읽던 책이 이미 선택된 채**, 커서가 문장 칸에 놓인 상태로 열립니다.
  붙여넣고 저장 — 그게 전부입니다.
- 저장해도 시트는 닫히지 않습니다. 같은 책에 다음 밑줄을 바로 이어 긋고(`n개째`),
  다 그었으면 `그만 긋기`로 내려옵니다.
- 쪽수는 작은 칸 하나, 메모·태그·날짜·사진은 전부 선택이고 접혀 있습니다. 태그는 출처마다
  마지막에 쓴 것이 기본값으로 따라오므로, 같은 책이면 다시 적을 일이 없습니다.
- 영상 출처는 링크를 지닙니다 — 같은 영상의 메모마다 링크를 다시 붙이지 않습니다.
- 출처 칩을 길게 누르면 이름을 고치거나 지울 수 있습니다. 고친 제목은 그 출처의 밑줄에도
  반영됩니다. 같은 제목을 다시 등록하면 새로 만들지 않고 있던 출처를 씁니다.
- 출처는 `sources` 테이블에, 각 밑줄은 `entries.source_id`로 매달립니다. 서재·내보내기가
  그대로 동작하도록 제목·저자는 밑줄에도 복사해 둡니다. 출처 없이 남긴 옛 기록은
  마이그레이션이 제목별로 출처를 만들어 이어 줍니다.

## 화면

| 탭 | 역할 |
|----|------|
| 오늘 | 다시 만나는 밑줄 덱 · 유형 칩 바(1탭 캡처) · 할 일 · 오늘의 타임라인 |
| 서재 | 검색 · 형식 서가 · 갈피(태그) 칩 · 최신순/오래 안 읽은 순/아껴둔 것만 |
| 남기기 | 중앙 버튼 → 캡처 시트 (책·영상은 출처 선택 상태로 열림) |
| 흐름 | 실천의 무늬(먹점 4행) · 이번 주 운동 · 이달의 서재 |

## 디자인 언어

색은 둘뿐 — **종이와 먹**. 흰 지면(#FFFFFF)에 검은 글(#111111), 눌러 앉힌 면은 옅은 회색
(#F3F3F3), 밤은 #0C0C0C 위의 #F2F2F2. 강조색도 먹입니다 — 밑줄은 글과 같은 잉크로
그어지고, 위계는 색이 아니라 굵기·크기·간격으로만 만듭니다. 사용자가 쓴 것은
고운바탕(세리프), 앱이 말하는 것은 IBM Plex Sans KR — 이 한 줄이 전체 위계를 만듭니다.

## 옵시디언 내보내기

하루 한 문서(`YYYY-MM-DD`), YAML 프런트매터(date/types/tags), 유형별 H2 섹션,
blockquote 인용 관례. 설정에서 이번 주/이번 달/전체를 공유 시트로 내보냅니다.

## 기술

- Expo SDK 54 · TypeScript strict · expo-router · expo-sqlite (오프라인 전용, 서버 없음)
- `PRAGMA user_version` 기반 버전드 마이그레이션, 타입드 리포지토리 레이어
- 날짜·태그·덱 선정·마크다운 빌더는 순수 함수 (`src/core/`) — `npm test`로 검증
- 하루의 경계는 새벽 4시 (자정 넘어 쓴 일기는 어제의 일기)

```bash
npm install
npm run ios        # 개발 실행
npm run typecheck  # tsc --noEmit
npm test           # 코어 유닛 테스트 (node:test + tsx)
```
